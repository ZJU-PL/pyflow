Analysis Modules

PyFlow provides a comprehensive suite of static analysis engines for understanding Python programs. These engines consume the shared representations documented in Intermediate Representations.

For an introduction to analysis concepts, see:

  • Analyzing Python Code - Tutorial on running analyses

  • Architecture - Architecture overview

  • Algorithms - Algorithm details

Overview

PyFlow’s analysis modules are organized into several categories:

Graph Analysis

  • Call Graph Analysis - Call Graph construction and analysis

  • Intermediate Representations - CFG, CDG, DDG, PDG, CPG, data flow IR, and store graph

Data Flow Analysis

  • Flow-Sensitive Data Flow (FSDF) - Flow-Sensitive Data Flow analysis

  • IFDS/IDE Data Flow Engine - IFDS/IDE interprocedural data flow engine (taint, nullness, typestate)

  • Inter-procedural Analysis (IPA) - Inter-procedural Analysis

  • Constraint-based Analysis (CPA) - Constraint-based Analysis

Alias and Type Analysis

  • Alias Analysis - Flow-sensitive and k-CFA alias analyses

  • Type Information System - Type-information collection and inference

Shape and Object Analysis

  • Shape Analysis - Region-based shape analysis for data structures (reference counts, path info)

  • Variable Lifetime Analysis - Variable lifetime analysis (read/modify tracking, post-shape pipeline)

See also

Memory Reasoning Systems — Comprehensive comparison of all six memory/heap reasoning systems in PyFlow, including when to use each one.

Specialized Analysis

  • Program Point Numbering - Program point numbering

  • Analysis Result Dumping - Analysis result dumping and visualization

  • Statistics Collection and Reporting - Statistics collection and LaTeX report generation

  • Incremental Analysis Cache - Incremental analysis caching with BLAKE2b + SQLite

Analysis Configuration

PyFlow supports configurable analysis with different precision/performance trade-offs.

Context-Sensitive Analysis

By default, PyFlow performs context-insensitive analysis for performance. Enable context-sensitive analysis for more precise results:

pyflow optimize input.py --analysis cpa

context.set_config("cpa.context_sensitive", True)

Flow-Sensitive Analysis

Enable flow-sensitive analysis for statement-by-statement precision:

context.set_config("cpa.flow_sensitive", True)

Field-Sensitive Analysis

Enable field-sensitive analysis to track individual object fields:

context.set_config("cpa.field_sensitive", True)

Running Analyses

Command Line

PyFlow provides several CLI commands for running analyses:

  • pyflow optimize - Run analysis and optimization pipeline

  • pyflow callgraph - Build and analyze call graphs

  • pyflow ir - Dump intermediate representations (AST, CFG, SSA, CDG, DDG)

  • pyflow alias - Run alias analysis (flow-sensitive heap or k-CFA pointer)

  • pyflow security - Unified security analysis dispatching to ast-scanner, CPA, IFDS, or CPG engines

  • pyflow supply-chain - Generate CycloneDX SBOMs and audit distribution metadata

Programmatic Usage

Use the Python API for programmatic analysis:

from pyflow.analysis.cpa import InterproceduralDataflow
from pyflow.analysis.callgraph.constraint_based.api import extract_call_graph_constraint

# Run CPA
cpa = InterproceduralDataflow()
cpa.run(program)

# Build call graph
graph = extract_call_graph_constraint(source_code)

Analysis Results

PyFlow produces detailed analysis results:

Text Output

Human-readable text output for terminal:

pyflow ir input.py --dump-cfg main --dump-format text

JSON Output

Machine-readable JSON for programmatic processing:

pyflow ir input.py --dump-cfg main --dump-format json --dump-output ./out

SARIF Output

Standard SARIF format for CI/CD integration:

pyflow security input.py --format sarif --output results.sarif
