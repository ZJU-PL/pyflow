Alias Analysis

PyFlow provides two alias-analysis implementations for different precision and integration requirements:

  • Flow-Sensitive Alias Analysis models order-aware heap effects, escape state, and strong versus weak updates over PyFlow IR.

  • k-CFA Alias Analysis computes a context-sensitive, monotone points-to solution from Python source using the migrated PythonStAn solver.
