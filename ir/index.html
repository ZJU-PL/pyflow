Intermediate Representations

The pyflow.ir package contains PyFlow’s shared program representations and graph infrastructure. Analysis engines in pyflow.analysis consume these structures; they are kept separate so representations are not confused with the algorithms that operate on them.

Package Layout

  • Control Flow Graph (CFG) — Control Flow Graph construction, dominance, and SSA support

  • Control Dependence Graph (CDG) — Control Dependence Graphs

  • Data Flow Intermediate Representation — Lowered data flow intermediate representation

  • Data Dependence Graph (DDG) — Data Dependence Graphs

  • Program Dependence Graph (PDG) — Program Dependence Graphs

  • Code Property Graph (CPG) — Code Property Graphs and CPG-backed taint infrastructure

  • Store Graph Intermediate Representation — Shared heap and points-to representation

  • IR Revision — IR revision summary (completed)

The corresponding source and test trees mirror this organization under src/pyflow/ir and tests/ir.
