Language API

The language module’s programmatic API provides the building blocks that higher-level analysis and optimization passes build on.

For the public-facing query and entrypoint API, see PyFlow API.

Core Language Modules

AST Construction

The pyflow.language.python.ast module defines all IR node types used throughout the analysis pipeline. See AST for Python for the complete node reference.

from pyflow.language.python import ast
from pyflow.language.python.program import Object

const = ast.Existing(Object(42))
local = ast.Local("x")
assign = ast.Assign(const, [local])

Program Model

The pyflow.language.python.program module provides the object and type model:

from pyflow.language.python.program import (
    Object,
    ImaginaryObject,
    TypeInfo,
    ProgramDescription,
)

AST Transformations

from pyflow.language.python.collapser import Collapser
from pyflow.language.python.fold import apply as fold_apply
from pyflow.language.python.defuse import DefUseVisitor
