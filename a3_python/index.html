a3_python

The a3_python package is a research-oriented analysis stack embedded inside this repository. It focuses on semantic bug finding, taint analysis, interprocedural reasoning, dynamic-symbolic refinement, and barrier-certificate based safety proofs for Python programs.

This section adapts the original standalone a3-python project notes into the documentation structure used by PyFlow.
